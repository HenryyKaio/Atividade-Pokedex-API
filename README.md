# Atividade-Pokedex-API
Atividade de mostrar um pokemon em um card usando dados da pokemon api
https://henryykaio.github.io/Atividade-Pokedex-API/


A maior dificuldade que eu resolvi: 
Professor, pra mim a maior dificuldade que eu passei no código foi a parte de fazer o botão de próximo e o botão de anterior. Parece simples, mas eu não conseguia resolver de jeito nenhum. Confesso que foi muito tentador pedir pra IA resolver isso pra mim e só entender como ela fez, mas pensei que dessa maneira eu não estaria treinando meu raciocínio e minha habilidade de resolver problemas adversos em situações difíceis, por isso me esforcei a pensar em uma maneira de resolver. Antes, eu estava puxando os dados da API e colocando eles na carta tudo em uma função só, então cheguei a conclusão de que para resolver esse problema, como eu teria que pegar o id do pokemon e somar +1 para ir para próximo e então colocar na carta de novo, a melhor coisa a se fazer era separar as funções. Então criei uma função que pegava os dados da API e outra que colocava na carta. A partir daí, foi fácil resolver pensando na lógica de puxar os dados, mudar o que eu precisava mudar e então colocar na carta.
